# CS2 map icons

The icons in `assets/map-icons/` come from [MurkyYT/cs2-map-icons](https://github.com/MurkyYT/cs2-map-icons), commit `6dcfb3a770afc08a16c4e843c51b873cac7fc4d5`.

Included source files: `images/de_mirage.png`, `images/de_inferno.png`, `images/de_ancient.png`, and `images/de_dust2.png`.

The upstream repository states that the map icons are property of Valve Corporation. The original PNG files are included without modification. They are displayed locally so the website does not depend on requests to GitHub at runtime.
